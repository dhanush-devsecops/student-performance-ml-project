# 🗓️ Week 2 — Student Performance Prediction

## 🎯 Objective

Build Machine Learning models to predict student performance using academic and behavioral factors.

## Dataset Features

* Gender
* Attendance Rate
* Study Hours Per Week
* Previous Grade
* Extracurricular Activities
* Parental Support
* Online Classes Taken
* Final Grade

## Machine Learning Models

### Linear Regression

Baseline regression model.

### Decision Tree Regressor

Captures non-linear relationships.

### Random Forest Regressor

Ensemble model delivering superior performance.

## Evaluation Metrics

* R² Score
* MAE
* MSE
* RMSE

## Key Findings

* Study Hours strongly influence final grades.
* Attendance Rate is a major predictor.
* Random Forest achieved the best performance.

## Skills Gained

* Feature Engineering
* Model Training
* Model Evaluation
* Regression Analysis
