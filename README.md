# 🎓 Student Performance Prediction - ML Project

## 📌 Overview
This project focuses on analyzing student data and building Machine Learning models to predict final grades based on academic and behavioral features.

It includes:
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Predictive Modeling
- Model Evaluation
- Feature Importance Analysis

---

## 📊 Problem Statement
Predict the **Final Grade** of students using features like:
- Study hours
- Attendance rate
- Previous grades
- Parental support
- Extracurricular activities

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## 🤖 Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

---

## 📈 Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Encoding
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Feature Importance Analysis

---

## 🏆 Results
- Random Forest performed best among all models
- Study hours and attendance were key influencing factors
- Model evaluation was done using R² Score
